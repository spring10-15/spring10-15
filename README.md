# Springwater · 山泉水有点甜

AI 产品经理，非编程出身。日常把 AI 能力落到企业业务流程里，也用 AI 协作做自己想用的产品。

近期主要围绕智能客服、专家智能体、文档处理与 AI 测评做产品实践，关注复杂需求如何变成清晰、可用、可验证的方案。

[个人网站](https://springwater-site.vercel.app/zh/) · [播客《山泉水有点甜》](https://springwater.podcast.xyz)
