# spring10-15

仓库按用途分为五类。分类不靠目录（GitHub 没有目录层级），靠统一的 `topics` 命名空间：
`cat-*` 标类别，`status-*` 标状态，fork 类仓库额外带 `fork-follow` 与 `upstream-<owner>`。
